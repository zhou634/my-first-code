什么是 Mindustry？

一个融合塔防、工厂自动化与即时战略的开源杰作。

Mindustry 是一款由 Anuken 开发的开源沙盒塔防游戏，融合了工厂自动化、资源管理与即时战略元素。

玩家需要在行星上采集资源、建造传送带网络、部署防御炮塔，在抵御一波波敌人进攻的同时，不断扩展自己的工业基地。游戏拥有丰富的科技树、多样的炮塔与单位，以及强大的逻辑控制系统。

支持单人战役、多人协作与PvP 对战，更有活跃的社区创作大量 Mod 与自定义地图。完全免费且开源，可在 Windows、macOS、Linux、Android 和 iOS 上运行。

核心特色

Mindustry 将多种玩法深度融合，创造出独一无二的游戏体验。

塔防策略

部署数十种不同炮塔——从基础的双管炮到毁灭性的熔毁射线，每种炮塔都有独特的攻击方式与适用场景。合理安排防线，在敌人行军路线上一层层削弱他们。

工厂自动化

像 Factorio 一样用传送带、管道、路由器搭建流水线。将矿石冶炼成金属，再加工为弹药与建筑材料，全自动供给前线炮塔。设计出高效的分拣与分配网络是游戏的核心乐趣。

逻辑控制系统

内置微型处理器系统，支持可视化编程。用逻辑处理器控制炮塔开关、监测资源库存、自动调节生产线。甚至可以编写简单的 AI 来管理无人机群。

多星球探索

在 Serpulo 和 Erekir 两颗行星上展开冒险。每个星球拥有截然不同的资源体系、科技树与敌人。攻克一个个区域，将生产成果带回核心基地解锁更高级科技。

多人联机

支持最多 16 名玩家同时在线。合作模式下共同建设与防御，PvP 模式下互相攻伐。支持专用服务器与局域网联机，延迟低、体验流畅。

Mod 与社区

完全开源，拥有极其活跃的 Mod 社区。通过内置 Mod 浏览器一键安装各种内容扩展——新炮塔、新单位、新星球、甚至全新玩法模式。支持 Java 和 JSON 编写 Mod。

核心玩法机制

从零开始，一步步打造你的自动化帝国。

1

采集与冶炼

使用钻头开采铜、铅、钛、钍等矿石，通过传送带运往熔炉冶炼成金属锭。不同矿石需要不同的开采与冶炼设备，合理布局是关键。

2

生产与供应链

将金属锭进一步加工为弹药、建筑材料与高级组件。用路由器、分拣器与桥接传送带构建复杂的物流网络。平衡生产与消耗，避免资源瓶颈。

3

防御与战斗

敌人会从固定路线（或空中）进攻你的核心。用墙壁阻挡、炮塔输出、修补无人机维修，构建多层立体防线。不同敌人有不同的抗性与弱点，需要针对性地搭配炮塔类型。

4

科技与扩张

通过科技树解锁更高级的炮塔、单位与工厂设备。派遣单位攻占敌方基地，或发射资源到轨道以解锁全局升级。逐步从一个小型前哨站发展为行星级工业帝国。
